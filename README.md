# Hệ Thống Quản Lý Website Bán Laptop (QuanLyBanLaptop)

Đồ án cuối kỳ môn **Công nghệ Java** – Nhóm 5 thành viên (Phiên bản khởi tạo Giai đoạn A - đang ghép nối module).

> **Lưu ý:** Đây là nhánh khởi tạo ban đầu để từng thành viên đưa phần việc phụ trách lên kho Git trước khi tiến hành tích hợp toàn hệ thống ở bước tiếp theo.

## Cấu hình máy cá nhân
Copy `laptop-shop-web/src/main/resources/application.properties.example` thành `application.properties` và điền mật khẩu SQL Server của máy bạn trước khi chạy.
