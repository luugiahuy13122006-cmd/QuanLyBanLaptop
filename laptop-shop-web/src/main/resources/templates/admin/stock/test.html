Cơ chế chống Race Condition
  • Pessimistic Locking: @Lock(PESSIMISTIC_WRITE) – SQL Server khóa row khi đọc để cập nhật
  • @Transactional: Mỗi luồng thực hiện trong transaction độc lập
  • ExecutorService: Quản lý thread pool, CountDownLatch đảm bảo tất cả bắt đầu cùng lúc
  • Log luồng: Xem console của ứng dụng để thấy tên luồng trong log
